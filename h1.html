Python Full Stack

Python Full Stack Development means developing both the frontend and backend of a website or web application using different technologies, including Python.

A Python Full Stack Developer works on both the user interface (frontend) and the server-side functionality.

It includes:-

  1. Frontend
  2. Backend
  3. Database
  4. Version Control

Frontend Development:- Technologies

Frontend is the part of a website that users can see and interact with.

  • HTML- Creates the structure of a webpage
  • CSS - Adds styles and designs to a webpage
  • JavaScript - Makes webpages interactive.
  • Bootstrap - Helps create responsive designs.
  • React.js - Builds interactive user interfaces.

Backend Development:- Technologies

Backend is the server-side part of a website. It handles data, business logic and user requests.

  • Python - Backend programming language
  • Django - Python framework used to develop web applications.
  • Flask - Lightweight Python web framework.
  • REST API - Helps frontend and backend communicate.

Database :- Technologies

A database stores and manages application data.

  • MySQL
  • SQLite
  • MongoDB

Version Control

Used to manage and track code changes.

  1. Git
  2. GitHub
